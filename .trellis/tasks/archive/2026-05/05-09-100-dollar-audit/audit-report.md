## 2. $100 规模下的痛点分析

### 痛点 A: 单一策略 + 超低赔率 = 龟速复利

**现状**: 只剩 gopfan2 一个策略，且预期年化仅 ~22%。

**数学**:
```
$100 → 年化22% → $122 (第一年)
$122 → 年化22% → $149 (第二年)
```

**问题**: 赌博式打法的目标是快速翻倍，但22%年化对$100毫无意义。

**根因**: 5个策略被删除的核心原因是"中部桶负EV"，但这个结论是在 **bid=$0.01/ask=$0.99** 的结构假设下得出的。实际上：
- Polymarket 订单簿并非都是 $0.01/$0.99
- 真实订单簿有 depth，中部桶有 resting limit orders
- 删除策略时可能过于保守

### 痛点 B: Fill Rate 极低

**现状**: FillModel 对尾部桶设 10% fill probability。

**$100 影响**:
- 每天扫描36城市 × 多个桶 = ~100-500个信号
- 10% fill rate → 10-50个成交
- 但 Kelly 10% × $100 = $10 单笔 → 以 $0.01 price = 1000 contracts
- 尾部桶深度可能只有 $10-50，所以实际成交可能更低

### 痛点 C: 费用侵蚀严重

**费用栈 (尾部YES @ $0.01)**:
| 费用 | 比例 | 对$100的影响 |
|------|------|-------------|
| Taker fee | 0.5-1.25% | $0.05-0.12 |
| Tail penalty | 5% | $0.50 |
| Ghost trade loss | 2% (live) | $0.20 |
| Slippage | 1% | $0.10 |
| Forecast penalty | 5% | $0.50 |
| **总计** | **~13.5%** | **$1.35 per trade** |

**$100 影响**: 单笔 $10 的交易，费用占 13.5%，需要 edge >13.5% 才有正EV。

### 痛点 D: 最低交易量门槛

```python
# engine.py
if size * rec.bucket.yes_price < 0.5:
    continue  # 跳过 <$0.50 的交易
```

**$100 影响**: Kelly 10% × $100 = $10, 以 $0.01 price = 1000 contracts × $0.01 = $10 > $0.50 ✅
这个门槛对$100不是问题。

### 痛点 E: Max Total Exposure 限制

```python
max_total_pct = 0.30  # 总暴露不超过 bankroll 的 30%
```

**$100 影响**: $100 × 30% = $30 最大总暴露。这在 $100 规模下过于保守。

### 痛点 F: 缺少蒙特卡洛压力测试

**现状**: 回测引擎只有单次运行，没有多路径模拟。
**$100 影响**: 无法评估破产概率和资金曲线的置信区间。

### 痛点 G: 缺少 $100 专用指标

**缺失指标**:
- 破产概率 (资金归零概率)
- 雪球倍数分布 (P50/P90/P99)
- 每周/月复利效率
- 最小生存期 (连续亏损后仍能交易的天数)
- $100→$500→$2000 路径概率

## 3. $100 适配机会分析

### 机会 A: 高赔率长尾桶重仓

**思路**: 极端温度桶 (YES price $0.01-$0.03)，赔率 33:1 到 99:1。

**可行性**:
- 真实 edge: model_prob 5-10% vs price 1-3% = edge 3-8%
- 但费用 ~13.5% 吃掉了大部分 edge
- **需要找到 edge > 15% 的桶才有正EV**

**$100 打法**: 允许单笔 50-80% bankroll (突破当前 10% 限制)
- $60 all-in 某个超低概率桶
- 赢了 → $60 × 99 = $5940
- 输了 → 亏 $60
- 概率 5% → EV = 0.05 × $5940 - 0.95 × $60 = $297 - $57 = +$240

**风险**: 95% 概率亏 $60，但 5% 概率赢 $5940。

### 机会 B: Laddering 多桶组合

**思路**: 同时买入多个尾部桶，分散风险。

**示例**: NYC 某天有 15 个桶
- 买5个尾部YES (每个 $0.02, edge 5%)
- 每桶投入 $20, 总投入 $100
- 期望: 1-2个桶 hit → 收回 $20-40 × 50 = $1000-2000

### 机会 C: 预报 vs 市场高赔率套利

**思路**: 当模型概率远高于市场定价时 (edge > 20%)，重仓。

**条件**:
- 需要多源共识 (GFS + ECMWF + NWS 都同意)
- 市场定价极低 ($0.01-$0.05)
- 距离 resolution > 12h

### 机会 D: Elite Wallet 跟单

**思路**: 监控 Polymarket 上胜率最高的钱包，跟随其尾部桶交易。

**可行性**: 需要 Dune Analytics 或 Polygonscan 查询 top traders。

### 机会 E: Resolution 异常/延迟

**思路**: 当 resolution 延迟时，市场可能 mispriced。

**示例**: 如果实际温度已经确定但市场还没 settle，可以在 mispriced 桶上套利。
