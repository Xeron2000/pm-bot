# PM-Bot $100 Aggressive Mode 规范

## 概述
为 $100 USDC 极小资金设计的极致激进交易模式。

## 风险态度
- **风险等级**: 极高 (接近赌博式)
- **接受波动**: 30-100% 日波动, 可能清仓
- **破产概率**: 预期 30-50%
- **目标**: 快速复利滚雪球, 争取 $100→$500→$2000

## 核心策略包 (5个)

### 1. gopfan2 (Tail-YES Lottery)
- **逻辑**: 买低价YES尾部桶 ($0.01-$0.15)
- **胜率**: ~15-25%
- **赔率**: 1:4 到 1:99
- **Kelly**: 25-40%
- **适合**: 单笔 $1-10

### 2. laddering (多桶梯子)
- **逻辑**: 在预测温度范围内密集建仓6个桶
- **灵感**: neobrother 策略 (658天 $6,320 利润)
- **Kelly**: 60%
- **适合**: 中等确定性场景

### 3. tail_no_barbell (尾部NO杠铃)
- **逻辑**: 70%资金买tail-NO (稳), 30%买tail-YES (搏)
- **灵感**: Hans323 策略 (1118次 $1,875 利润)
- **Kelly**: 60%
- **适合**: 平衡风险收益

### 4. forecast_arb (预报套利)
- **逻辑**: 模型与市场价格差距 >15% 时建仓
- **Kelly**: 80%
- **适合**: 天气突变时

### 5. resolution_delay (结算延迟)
- **逻辑**: 在UMA oracle确认前买入已确定的赢家
- **Kelly**: 80%
- **适合**: 结算延迟窗口

## 仓位管理 (Aggressive 100 Mode)
| 参数 | 值 | 说明 |
|------|-----|------|
| max_single_pct | 50-60% | 单笔最大占银行 |
| max_total_pct | 80% | 总暴露最大80% |
| kelly_fraction | 40-80% | 激进Kelly |
| stop_loss_pct | 50% | 50%回撤止损 |
| min_acceptable_edge | 3-15% | 按策略调整 |

## 费用模型 (Polymarket Weather)
| 价格区间 | Taker费率 |
|----------|----------|
| 5¢ (tail) | 0.24% |
| 10¢ | 0.45% |
| 20¢ | 0.80% |
| 50¢ | 2.50% |

**结论**: tail桶费率极低, 适合$100高频交易。

## 复利规则
- 每日/每周结算后, 利润全部再投入
- 不提取利润, 直到达到分阶段目标
- 达到目标后, 考虑降低风险等级

## 分阶段目标
| 阶段 | 目标 | 预期时间 | 风险等级 |
|------|------|---------|----------|
| 0 | $100 | 起点 | - |
| 1 | $500 | 30-60天 | 极高 |
| 2 | $2000 | 30-60天 | 高 |
| 3 | $10000 | 60-120天 | 中高 |

## Monte Carlo 模拟器
- 1000+ 路径模拟
- 灵敏度分析 (conservative → yolo)

- 雪球里程碑追踪

## Snowball Metrics
- survival_rate: 存活率
- bankruptcy_rate: 破产率
- reach_500_rate: 达到$500概率
- max_drawdown_pct: 最大回撤
- consecutive_losses: 连续亏损

## 禁止行为
- 使用已被证明负EV的策略
- 忽略费用侵蚀
- 不做压力测试就实盘

## 心理管理
- 接受可能亏光 $100 的现实
- 不追加资金, 只用初始 $100
- 每周回顾交易记录
- 连续亏损3天后暂停1天
